关于 XsGraph

XsGraph 是一个为独立开发者和小型团队设计的轻量级 C++ 游戏开发框架。它的目标是：

  • 极简接入 — 只需包含头文件即可使用，无需复杂的构建系统
  • 现代 C++ — 基于 C++20 与 sfml，充分利用 RAII 与类型推导
  • 高性能 — 批处理渲染、智能状态管理、最小驱动开销
  • 跨模块一致 — 绘图、窗口、输入、音频共享同一命名空间与编码风格

无论你是在做游戏原型、可视化工具还是创意编程，XsGraph 都能让你在 5 分钟内跑起第一个窗口。

基本框架

只需 30 行代码，创建一个窗口并绘制一个旋转的正方形：

#include "Xs.h"

int main() {
    RenWin window;
    CreateGraphWindow(window, 100, 100, 800, 600, "Hello XsGraph");

    float angle = 0;
    while (!IsClose(window)) {
        UpdateMsg(window);
        DelayFps(60, window);

        BeginDraw(window, Color(20, 15, 30));
        SetColor(Color(124, 58, 237));
        DrawRectRotated(400, 300, 200, 200, angle, 0.5f, 0.5f);
        EndDraw(window);

        angle += 1.5f;
    }
    return 0;
}
