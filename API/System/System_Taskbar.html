进度条状态

ProgressState 枚举

值说明
NOPPROGRESS无进度（清除任务栏进度条）
INDETERMINATE不确定模式（持续滚动动画）
NORMAL正常进度
ERROR错误状态（红色）
PAUSED暂停状态（黄色）

SetTaskBarVisible

参数

参数类型说明
