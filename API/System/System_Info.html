System_Info

命名空间：xs::XSystem::Info

屏幕尺寸

GetScreenSize

Vector2i GetScreenSize();

返回值

返回主显示器分辨率，格式为 Vector2i（x = 宽，y = 高）。

工作区尺寸

GetWorkRectSize

Vector2i GetWorkRectSize();

返回值

返回工作区尺寸（排除任务栏等系统区域），格式为 Vector2i。

任务栏尺寸

GetTaskbarSize

Vector2i GetTaskbarSize();

返回值

返回任务栏尺寸，格式为 Vector2i（宽度或高度取决于任务栏位置）。
