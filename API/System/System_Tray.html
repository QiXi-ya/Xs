绑定窗口

BindWindow

bool BindWindow(HWND hwnd);

参数

参数类型说明
hwndHWND要绑定到托盘的目标窗口句柄。

返回值

成功返回 true，失败返回 false。

添加图标

AddIcon（宽字符）

bool AddIcon(std::wstring tooltip = nullptr, UINT resId = 0);

参数

参数类型说明
tooltipstd::wstring托盘提示文本；为 nullptr 时不显示提示。
resIdUINT资源 ID；为 0 时加载程序图标。

AddIcon（窄字符）

bool AddIcon(std::string tooltip = nullptr, UINT resId = 0);

参数

参数类型说明
tooltipstd::string托盘提示文本（窄字符版本）。
resIdUINT资源 ID；为 0 时加载程序图标。

返回值

成功返回 true，失败返回 false。

气泡通知

InfoType 枚举

值说明
BALLOON_NONE默认样式
BALLOON_INFO通知（蓝色信息图标）
BALLOON_WARNING警告（黄色警告图标）
BALLOON_ERROR错误（红色错误图标）

ShowBalloon

bool ShowBalloon(
    LPCWSTR title,
    LPCWSTR text,
    InfoType type = InfoType::BALLOON_INFO,
    DWORD timeoutMs = 5000
);

参数

参数类型说明
titleLPCWSTR气泡通知标题。
textLPCWSTR气泡通知正文。
typeInfoType通知类型，默认 BALLOON_INFO。
timeoutMsDWORD超时时间（毫秒），默认 5000。

返回值

成功返回 true，失败返回 false。
