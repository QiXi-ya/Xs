3D 位置

设置音频在 3D 空间中的位置，支持相对监听器或世界坐标。

Set3DPosition（MUSIC）

void Set3DPosition(MUSIC& music, float x, float y, float z, bool relative);

参数

参数类型说明
musicMUSIC&要设置 3D 位置的音频。
x, y, zfloat3D 空间坐标。
relativebooltrue = 相对于监听器位置；false = 世界坐标。

Set3DPosition（SOUND）

void Set3DPosition(SOUND& sound, float x, float y, float z, bool relative);

参数

参数类型说明
soundSOUND&要设置 3D 位置的音频。
x, y, zfloat3D 空间坐标。
relativebooltrue = 相对于监听器位置；false = 世界坐标。

最小距离

设置音频音量保持最大值的起始距离。距离小于此值时音量为 100%，超过后开始衰减。

参数

参数类型说明

音量衰减

设置音频随距离衰减的速率。值越大，音量随距离下降越快。

SetAttenuation（MUSIC）

void SetAttenuation(MUSIC& music, float attenuation);

参数

参数类型说明
musicMUSIC&要设置衰减的音频。
attenuationfloat衰减值，越大衰减越快。

SetAttenuation（SOUND）

void SetAttenuation(SOUND& sound, float attenuation);

参数

参数类型说明
soundSOUND&要设置衰减的音频。
attenuationfloat衰减值，越大衰减越快。

实际音量

获取经过 3D 衰减后的实际播放音量。

GetTrueVolume（MUSIC）

float GetTrueVolume(MUSIC& music);

参数

参数类型说明
musicMUSIC&要获取实际音量的音频。

返回值

返回衰减后的实际音量值（0.0 ~ 100.0）。

此值与 GetVolume 不同：GetVolume 返回设置值，GetTrueVolume 返回经过 3D 距离衰减后的实际值。

GetTrueVolume（SOUND）

float GetTrueVolume(SOUND& sound);

参数

参数类型说明
soundSOUND&要获取实际音量的音频。

返回值

返回衰减后的实际音量值（0.0 ~ 100.0）。
