命名空间：xs | 着色器管理

ApplyShader — 应用着色器

为指定纹理应用着色器效果，可选绑定 uniform 参数。

ApplyShader

 void ApplyShader(
    Texture& texture,
    sf::Shader& shader,
    std::function<void(sf::Shader&)> bind = nullptr
);

参数

参数类型说明
textureTexture&要应用着色器效果的纹理对象。
shadersf::Shader&已编译链接的着色器对象。
bindstd::function<void(sf::Shader&)>可选的 uniform 绑定回调，用于设置自定义参数；默认为 nullptr。
调用前请确保着色器已成功加载。绑定回调中可设置纹理采样器、颜色、矩阵等 uniform 变量。

load — 从文件加载（顶点+片段）

从磁盘文件加载并编译顶点着色器和片段着色器。

load

 bool load(
    const std::string& key,
    const std::filesystem::path& vertPath,
    const std::filesystem::path& fragPath
);

参数

参数类型说明
keyconst std::string&着色器索引键，用于后续通过 GetShader 查找。
vertPathconst std::filesystem::path&顶点着色器源文件路径。
fragPathconst std::filesystem::path&片段着色器源文件路径。

返回值

加载并编译成功返回 true，失败返回 false。

请使用 GetShader 函数通过 key 查找并使用已加载的着色器。

    const std::string& key,

    std::string_view fragSource

ClearShader — 清除全部着色器

销毁并移除所有已加载的着色器。

ClearShader

 void ClearShader();
调用后所有已加载的着色器均会被销毁，通过 GetShader 获取的旧指针将变为悬空指针，请勿继续使用。
