Batch 类

xs::XBatch 提供渲染批处理管理，支持自动/手动两种模式，用于高效收集并提交绘制命令到 GPU。

Shader 类

xs::XShader 提供 GLSL 着色器管理，支持从文件或源码加载，应用于渲染目标。

Color 类

xs::XColor 提供颜色处理工具，包括灰度化、明暗调整、透明度、颜色比较等。被 Graph/Image/Text 等所有绘制模块共用。

xs::XEase 提供动画缓动函数与数值结构体，支持 15 种缓动曲线（In / Out / InOut 三种模式），每种函数都配有 x=时间 / y=值的精确可视化曲线图。

xs::XEase EaseAnimationTranslate 便捷封装 查看详情 >
