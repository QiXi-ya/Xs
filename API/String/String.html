Find — 查找

在字符串中查找子串位置，或判断是否包含子串。

find（string）

 size_t find(const std::string& str, const std::string& sub, size_t offset = 0);

参数

参数类型说明
strconst std::string&被搜索的原字符串。
subconst std::string&要查找的子串。
offsetsize_t起始搜索偏移量，默认 0。

返回值

返回子串首次出现的索引位置；未找到时返回 std::string::npos。

find（wstring）

 size_t find(const std::wstring& str, const std::wstring& sub, size_t offset = 0);

参数

参数类型说明
strconst std::wstring&被搜索的宽字符串。
subconst std::wstring&要查找的宽字符子串。
offsetsize_t起始搜索偏移量，默认 0。

返回值

返回子串首次出现的索引位置；未找到时返回 std::wstring::npos。

Replace — 替换

将字符串中所有匹配的子串替换为目标子串。

replace（string）

 std::string replace(
    const std::string& str,
    const std::string& from,
    const std::string& to
);

参数

参数类型说明
strconst std::string&原字符串。
fromconst std::string&要被替换的子串。
toconst std::string&替换后的目标子串。

返回值

返回替换后的新字符串（原字符串不变）。

replace（wstring）

 std::wstring replace(
    const std::wstring& str,
    const std::wstring& from,
    const std::wstring& to
);

参数

参数类型说明
strconst std::wstring&原宽字符串。
fromconst std::wstring&要被替换的宽字符子串。
toconst std::wstring&替换后的目标宽字符子串。

返回值

返回替换后的新宽字符串（原字符串不变）。
