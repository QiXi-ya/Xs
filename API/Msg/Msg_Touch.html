Msg_Touch

命名空间：xs | 所属类：XMsg::TouchMsg

触控状态

IsTouching

判断当前是否有触控点正在接触屏幕。

bool IsTouching();

GetTouchNum

获取当前触控点数量。

int GetTouchNum();

位置与大小

GetTouchPos

获取第一个触控点的位置。

Vector2i GetTouchPos();

返回值

返回触控点的 Vector2i 像素坐标。

GetTouchSize

获取触控接触区域的大小。

int GetTouchSize();

返回值

返回触控接触区域的直径（像素）。

触控滚轮

GetTouchWheel

获取触控产生的滚轮值。

int GetTouchWheel();

返回值

返回滚轮值，为 120 的整数倍。

设备支持

IsTouchSupported

判断当前设备是否支持触控输入。

bool IsTouchSupported();

返回值

支持返回 true，否则返回 false。
