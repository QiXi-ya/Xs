Msg_HotKey

命名空间：xs | 所属类：XMsg::KeyMsg::HotKey

注册热键

RegisterHotKey

注册或更新一个热键组合。同名热键重复注册会覆盖旧值。

void RegisterHotKey(const std::string& name, std::vector<VK::VKC> VK);

参数

参数类型说明
nameconst std::string&热键标识名，用于后续查询与注销。
VKstd::vector<VK::VKC>热键组合（可包含修饰键 + 主键）。

查询热键

IsHotKeyPressed

判断指定热键是否在本帧被按下。

bool IsHotKeyPressed(const std::string& name);

参数

参数类型说明
nameconst std::string&热键标识名。

返回值

按下返回 true，否则返回 false。

注销热键

UnRegisterHotKey

注销指定热键，注销后该名称可重新注册。

void UnRegisterHotKey(const std::string& name);

参数

参数类型说明
nameconst std::string&要注销的热键标识名。
