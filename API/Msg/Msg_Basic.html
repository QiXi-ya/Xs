Msg_Basic

命名空间：xs | 所属类：XMsg

XMsg — 消息主类

UpdateMsg

更新窗口消息队列，每帧必须调用一次。

void UpdateMsg(RenWin& Dest);

参数

参数类型说明
DestRenWin&目标窗口，消息将绑定到此窗口。

IsClose

判断当前窗口是否收到关闭消息。

bool IsClose(RenWin& window);

参数

参数类型说明
windowRenWin&目标窗口。

返回值

窗口被请求关闭时返回 true，否则返回 false。

ResetCloseMsg

重置关闭消息状态，调用后 IsClose 将返回 false。

void ResetCloseMsg();

SetSleepTime

设置消息循环的睡眠时间（毫秒），用于控制主循环节奏。

void SetSleepTime(int time);

参数

参数类型说明
timeint睡眠时间（毫秒）。

ClearMsg

清理消息缓冲区，丢弃所有未处理的消息。

void ClearMsg();
