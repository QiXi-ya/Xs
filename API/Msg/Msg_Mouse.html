Msg_Mouse

命名空间：xs | 所属类：XMsg::MouseMsg

鼠标位置

GetMousePosWindow

获取鼠标在指定窗口上的像素坐标。

Vector2i GetMousePosWindow();

返回值

返回鼠标在窗口坐标系中的 Vector2i 位置。

GetMousePosWindowNormalization

获取鼠标在窗口上的归一化坐标（0~1）。

Vector2f GetMousePosWindowNormalization(int x = -1, int y = -1, int w = -1, int h = -1);

参数

参数类型说明
x, yint基准区域左上角；-1 表示使用整个窗口。
w, hint基准区域宽高；-1 表示使用整个窗口。

返回值

返回归一化的 Vector2f（范围 0~1）。

GetMousePosScreen

获取鼠标在屏幕上的像素坐标。

Vector2i GetMousePosScreen();

GetMousePosScreenNormalization

获取鼠标在屏幕上的归一化坐标。

Vector2f GetMousePosScreenNormalization(int x = -1, int y = -1, int w = -1, int h = -1);

参数

参数类型说明
x, yint基准区域左上角（屏幕坐标）。
w, hint基准区域宽高。

滚轮

GetMouseWheel

获取鼠标滚轮值，返回 120 的整数倍。

int GetMouseWheel();

返回值

滚轮向上为正，向下为负，步长为 120。

IsWheel

判断本帧是否发生了滚轮事件。

bool IsWheel();

IsMouseMove

判断本帧鼠标是否发生了移动。

bool IsMouseMove();

按键状态

IsMouseDown

判断指定鼠标键是否处于按下状态（持续帧检测）。

bool IsMouseDown(VK::VKC button);

参数

参数类型说明
buttonVK::VKC要检测的鼠标键（如 MouseLeft）。

IsMousePress

判断指定鼠标键是否在本帧刚刚按下（边沿触发）。

bool IsMousePress(VK::VKC button);

参数

参数类型说明
buttonVK::VKC要检测的鼠标键。

区域检测

IsMouseIn

判断鼠标是否在窗口的指定矩形区域内。

bool IsMouseIn(int x, int y, int w, int h);

参数

参数类型说明
x, yint区域左上角坐标。
w, hint区域宽高。

禁用区

SetBanZone

设置鼠标禁用区域，该区域内的鼠标消息在本帧内失效。

void SetBanZone(int x, int y, int w, int h);

参数

参数类型说明
x, yint禁用区域左上角。
w, hint禁用区域宽高。
