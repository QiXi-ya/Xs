字符输入

GetInPut

获取本帧输入的字符。

std::string GetInPut();

返回值

有输入时返回字符；退格返回 \b，回车返回 \n，无输入返回空串。

GetInPutNumber

在已有字符串基础上追加合法数字输入，过滤非数字字符。

std::string GetInPutNumber(std::string str);

参数

参数类型说明
strstd::string当前已输入的字符串，函数会在此基础上追加。

返回值

返回追加了合法数字输入的新字符串；输入不合法时返回原字符串。
