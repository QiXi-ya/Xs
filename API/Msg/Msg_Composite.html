区域复合检测

IsMouseInRectDown

判断指定鼠标键是否在指定矩形区域内被按下。

bool IsMouseInRectDown(VK::VKC VK, int x, int y, int w, int h);

参数

参数类型说明
VKVK::VKC要检测的鼠标键。
x, yint区域左上角坐标。
w, hint区域宽高。

返回值

在区域内按下返回 true。

GetMouseRectWheel

获取鼠标在指定区域内的滚轮值。

int GetMouseRectWheel(int x, int y, int w, int h);

参数

参数类型说明
x, yint区域左上角坐标。
w, hint区域宽高。

返回值

返回滚轮值，为 120 的整数倍。
