VK — 虚拟键码

命名空间：xs::VK::VKC

概述

xs::VK 类内嵌枚举 VKC，统一管理键盘、鼠标、功能键的虚拟键码。供 MouseMsg、KeyMsg、Composite、HotKey 等类使用。

注意：请使用键码名而不是十六进制
enum VKC {
    MouseLeft   = 0x01,  // 鼠标左键
    A           = 0x41,  // 字母键 A
    Fn1         = 0x70,  // 功能键 F1
    // ... 完整列表见下方
};
