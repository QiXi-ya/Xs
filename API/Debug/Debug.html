Log — 写入日志

将日志内容写入指定文件。

Log

 void Log(std::string text, std::wstring LogFilePath = L"QxDebug.log");

参数

参数类型说明
textstd::string要写入的日志内容。
LogFilePathstd::wstring日志文件路径，默认 L"QxDebug.log"（程序目录下）。
日志以追加模式写入，多次调用不会覆盖已有内容。

参数

参数类型说明
textstd::wstring要显示的调试信息（宽字符）。

DebugMsg（窄字符）

 void DebugMsg(std::string text);

参数

参数类型说明
textstd::string要显示的调试信息（窄字符）。
弹窗为模态对话框，会阻塞当前线程直到用户确认。不建议在高频循环中使用。

DebugPut — 缓冲写入

将调试信息送入内部缓冲区，可按等级分类，随后统一读取。

DebugPut（宽字符）

 void DebugPut(std::wstring text, int level = 0);

参数

参数类型说明
textstd::wstring调试信息内容。
levelint调试等级，默认 0。数值越大表示等级越高。

DebugPut（窄字符）

 void DebugPut(std::string text, int level = 0);

参数

参数类型说明
textstd::string调试信息内容。
levelint调试等级，默认 0。

GetDebug — 读取缓冲

获取缓冲区中累积的调试信息，宽字符与窄字符分别获取。

GetDebug（宽字符）

 std::vector<std::pair<std::wstring, int>> GetDebug();

返回值

返回缓冲区中所有调试信息的副本，每项为一个 pair<wstring, int>（内容 + 等级）。

GetDebugA（窄字符）

 std::vector<std::pair<std::string, int>> GetDebugA();

返回值

返回缓冲区中所有调试信息的副本（窄字符版本），每项为一个 pair<string, int>（内容 + 等级）。

返回的 vector 是缓冲区的副本，调用后缓冲区内容不会被清空。如需清空请手动处理。
