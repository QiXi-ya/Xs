xs::XBatch

命名空间：xs | 所属类：XBatch

BatchType — 批处理类型枚举

控制批处理是自动追加还是手动管理。

值说明
BATCH_AUTO自动模式，由系统自动管理批处理命令。
BATCH_HANDLED手动模式，由用户显式控制批处理。

begin — 开始批处理

开启渲染批处理，后续绘制命令将被收集到批处理队列中。

 void begin(Rt& target);

参数

参数类型说明
targetRt&渲染目标，批处理后的绘制将输出到此目标。
调用 begin 后必须配对调用 end，否则批处理不会提交。

end — 结束批处理

结束当前批处理并提交所有收集的绘制命令到渲染目标。

 void end();
不需要参数，渲染目标由 begin 时指定。

isBatching — 是否正在批处理

查询当前是否处于批处理进行中状态。

 bool isBatching();

返回值

如果当前正在批处理中返回 true，否则返回 false。

GetBatchType — 获取批处理类型

获取当前设置的批处理模式（自动或手动）。

 BatchType GetBatchType();

返回值

返回 BatchType 枚举值：BATCH_AUTO（自动）或 BATCH_HANDLED（手动）。

SetBatchType — 设置批处理类型

设置批处理模式。如果有不同绘制目标（如离屏渲染），建议使用手动模式。

 void SetBatchType(BatchType type);

参数

参数类型说明
typeBatchType批处理类型。BATCH_AUTO（自动）或 BATCH_HANDLED（手动）。
如果有不同绘制目标（比如离屏渲染），建议手动管理。自动 Batch 并不会执行最正确的批处理命令。

CheckDest — 检查并修正当前目标（内部函数）

检查当前渲染目标是否正确，必要时进行修正。此函数为内部使用，一般无需手动调用。

 void CheckDest(Rt& Dest);

参数

参数类型说明
DestRt&要检查和修正的渲染目标。
内部函数，由系统在批处理过程中自动调用。

addQuad — 添加四边形（内部函数）

向批处理队列中添加一个四边形（TriangleStrip 模式），用于绘制矩形或线段。此函数为内部使用。

 void addQuad(
    const sf::Vector2f& p0,
    const sf::Vector2f& p1,
    const sf::Vector2f& p2,
    const sf::Vector2f& p3,
    const sf::Color& color
);

参数

参数类型说明
p0const sf::Vector2f&四边形第一个顶点。
p1const sf::Vector2f&四边形第二个顶点。
p2const sf::Vector2f&四边形第三个顶点。
p3const sf::Vector2f&四边形第四个顶点。
colorconst sf::Color&四边形颜色。
内部函数，使用 TriangleStrip 图元类型。通常用于矩形填充和线段绘制。

addTriangleFan — 添加三角扇形（内部函数）

向批处理队列中添加一个三角扇形（TriangleFan 模式），用于绘制圆形、弧形或点。此函数为内部使用。

 void addTriangleFan(
    const std::vector<sf::Vector2f>& fan,
    const sf::Color& color
);

参数

参数类型说明
fanconst std::vector<sf::Vector2f>&三角扇形的顶点数组，第一个顶点为公共中心。
colorconst sf::Color&扇形颜色。
内部函数，使用 TriangleFan 图元类型。通常用于圆形、弧形和点集的绘制。

Entry — 批处理条目结构体

批处理队列中的单个绘制条目，包含图元类型和顶点数据。

struct Entry
{
    sf::PrimitiveType type;
    std::vector<sf::Vertex> vertices;
};

成员

成员类型说明
typesf::PrimitiveType图元类型（如 TriangleStrip、TriangleFan 等）。
verticesstd::vector<sf::Vertex>该条目的顶点数据数组。
