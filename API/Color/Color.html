参数

参数类型说明

IsColorSame — 颜色比较

判断两个颜色是否相似或相同，支持精确/相似两种模式，可选是否对比 Alpha 通道。

bool IsColorSame(
    const Color& colorA,
    const Color& colorB,
    bool UseAlpha = false,
    bool isExact = false,
    int VagueValue = 10);

参数

参数类型说明
colorAconst Color&目标颜色 A。
colorBconst Color&目标对比颜色 B。
UseAlphabool是否对比 Alpha 通道，默认 false（不对比）。
isExactbool是否精确对比（每个通道完全相等），默认 false（相似对比）。
VagueValueint相似对比时的允许差度，默认 10，值越小越严格。

返回值

如果相似或相同返回 true，否则返回 false。

当 isExact = true 时，每个颜色通道必须完全相等才会返回 true。 当 isExact = false 时，各通道差值在 VagueValue 范围内即视为相同。
