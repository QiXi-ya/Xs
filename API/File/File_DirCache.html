File_DirCache

命名空间：xs | 所属类：XFile::DirCache

保存目录

SetDirCache

 void SetDirCache(const std::wstring& key, const Path& path);

参数

参数类型说明
keyconst std::wstring&缓存标识键名。
pathconst Path&要保存的目录路径。
以键值对形式将目录路径存入缓存，方便后续快速取回。同一 key 可对应多个路径。

示例

XFile::DirCache::SetDirCache(L"LastOpen", L"D:/Projects/MyGame");

查找目录

GetDirCache

 std::vector<Path> GetDirCache(const std::wstring& key);

参数

参数类型说明
keyconst std::wstring&要查找的缓存标识键名。

返回值

返回该 key 对应的所有目录路径数组；key 不存在时返回空数组。

示例

auto dirs = XFile::DirCache::GetDirCache(L"LastOpen");
if (!dirs.empty()) {
    // 使用 dirs[0] 作为默认打开路径
}

删除缓存

RemoveDirCache

 void RemoveDirCache(const std::wstring& key);

参数

参数类型说明
keyconst std::wstring&要删除的缓存标识键名。
删除该 key 对应的所有缓存路径。key 不存在时不报错。

清除全部缓存

ClearDirCache

 void ClearDirCache();

清除所有已保存的目录缓存，释放全部键值对。

此操作不可恢复，调用前请确认。
