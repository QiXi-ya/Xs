File_GetDir

命名空间：xs | 所属类：XFile::GetDir

程序路径

ModulePath

 Path ModulePath();

返回值

返回当前可执行程序（.exe）所在的完整目录路径。

常用于定位程序同目录下的资源文件。

ProgramDir

 Path ProgramDir();

返回值

返回系统软件安装目录（通常为 C:\Program Files 或 C:\Program Files (x86)）。

TempPath

 Path TempPath();

返回值

返回系统临时文件目录（通常为 C:\Users\<用户>\AppData\Local\Temp）。

适合存放临时缓存，系统可能会自动清理。

系统目录

SystemDir

 Path SystemDir();

返回值

返回系统目录（通常为 C:\Windows\System32）。

WindowsDir

 Path WindowsDir();

返回值

返回 Windows 安装目录（通常为 C:\Windows）。

用户数据目录

AppDataLocal

 Path AppDataLocal();

返回值

返回当前用户的 AppData\Local 目录（C:\Users\<用户>\AppData\Local）。

适合存放本机独有的应用数据（不随用户漫游）。

AppDataRoaming

 Path AppDataRoaming();

返回值

返回当前用户的 AppData\Roaming 目录（C:\Users\<用户>\AppData\Roaming）。

适合存放需要随用户账户漫游的配置文件。

AppDataCommon

 Path AppDataCommon();

返回值

返回公共 AppData 目录（C:\ProgramData），所有用户共享。

用户文件夹

Desktop

 Path Desktop();

返回值

返回当前用户的桌面目录。

Documents

 Path Documents();

返回值

返回当前用户的文档目录。

Downloads

 Path Downloads();

返回值

返回当前用户的下载目录。

Pictures

 Path Pictures();

返回值

返回当前用户的图片目录。

Music

 Path Music();

返回值

返回当前用户的音乐目录。

Videos

 Path Videos();

返回值

返回当前用户的视频目录。
