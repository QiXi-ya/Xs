DisplayName（宽字符）

DisplayName

 std::wstring DisplayName(const Path& path);

参数

参数类型说明
pathconst Path&要获取文件名的路径。

返回值

返回文件名（含扩展名），宽字符版本。例如 L"image.png"。

示例

Path p = L"C:/Data/image.png";
std::wstring name = XFile::DisplayName(p);  // L"image.png"
