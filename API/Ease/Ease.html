XEase

命名空间：xs | 所属类：XEase

概述

xs::XEase 提供 22 种缓动函数，涵盖幂次、正弦、指数、圆形、回弹、弹跳、弹性七大类别，每种支持 In / Out / InOut 三种模式。每条曲线下方都配有 x=时间 / y=值 的可视化图表。

EaseValue 结构体

描述单个数值从 start 到 end 的缓动过程。

struct EaseValue {
    float start;        // 起始值
    float end;          // 目标值
    float value;        // 当前值（自动更新）
    int   frame;        // 当前帧
    int   totalframe;   // 总帧数
};

幂次缓动（Power）

最常用的缓动类型，通过指数控制加速/减速强度。默认 exp=3.0（三次方）。

easeIn

float easeIn(float t, float exp = 3.0f);

easeOut

float easeOut(float t, float exp = 3.0f);

easeInOut

float easeInOut(float t, float exp = 3.0f);

参数

参数类型说明默认
tfloat归一化时间 [0, 1]—
expfloat强度3.0
linear — 匀速运动
value = t，无加速度。
easeIn(t³) — 慢启动
开头极慢，结尾迅速到达终点。适合物体从静止加速。
easeOut(t³) — 快启动
开头极快，结尾缓慢到位。适合物体减速停靠。
easeInOut(t³) — S 形对称
前半段 easeIn，后半段 easeOut，中间最快。最常用。

正弦缓动（Sine）

基于正弦函数，曲线柔和自然，适合 UI 过渡动画。

easeInSine

float easeInSine(float t);

easeOutSine

float easeOutSine(float t);

easeInOutSine

float easeInOutSine(float t);

参数

参数类型说明默认
tfloat归一化时间 [0, 1]—
easeInSine — 正弦慢启动
比 easeIn 更柔和，类似自然加速度。
easeOutSine — 正弦快启动
比 easeOut 更柔和，自然减速。
easeInOutSine — 正弦 S 形
最柔和的 S 形曲线，适合 UI 动画。

指数缓动（Expo）

极端版本的加速/减速，适合快速切换场景。

easeInExpo

float easeInExpo(float t);

easeOutExpo

float easeOutExpo(float t);

easeInOutExpo

float easeInOutExpo(float t);

参数

参数类型说明默认
tfloat归一化时间 [0, 1]—
easeInExpo — 极端慢启动
前 70% 几乎不动，最后爆发。
easeOutExpo — 极端快启动
开头瞬间到位，后面微调节。
easeInOutExpo — 极端 S 形
两端几乎不动，中间极快切换。

圆形缓动（Circ）

基于圆方程的加速曲线，比幂次稍温和，比正弦稍锐利。

easeInCirc

float easeInCirc(float t);

easeOutCirc

float easeOutCirc(float t);

easeInOutCirc

float easeInOutCirc(float t);

参数

参数类型说明默认
tfloat归一化时间 [0, 1]—
easeInCirc — 圆弧慢启动
基于圆方程，比 easeIn 稍快但比 expo 温和。
easeOutCirc — 圆弧快启动
基于圆方程，开头冲刺，结尾圆滑到位。
easeInOutCirc — 圆弧 S 形
圆滑的 S 形，比正弦稍锐利。

回弹缓动（Back）

起步时向后蓄力或到达后超过终点再回弹，有"弹性感"。默认 s=1.70158。

easeInBack

float easeInBack(float t, float s = 1.70158f);

easeOutBack

float easeOutBack(float t, float s = 1.70158f);

easeInOutBack

float easeInOutBack(float t, float s = 1.70158f);

参数

参数类型说明默认
tfloat归一化时间 [0, 1]—
sfloat强度3.0
easeInBack — 向后蓄力
起步先向后拉再前进，有蓄力感。
easeOutBack — 超过终点再回弹
到达终点后稍微超过再弹回，有弹性感。
easeInOutBack — 蓄力+回弹
起步蓄力 + 终点回弹，戏剧感强。

弹跳缓动（Bounce）

模拟物体落地弹跳的衰减效果，多次小弧线逐渐平息。

easeInBounce

float easeInBounce(float t);

easeOutBounce

float easeOutBounce(float t);

easeInOutBounce

float easeInOutBounce(float t);

参数

参数类型说明默认
tfloat归一化时间 [0, 1]—
easeInBounce — 弹跳落地
像球落地前的多次弹跳减速。
easeOutBounce — 弹跳起飞
像球从地面弹起，多次衰减后到达终点。
easeInOutBounce — 双向弹跳

弹性缓动（Elastic）

像弹簧一样振荡衰减，视觉效果最夸张。默认 amplitude=1.0, period=0.3。

easeInElastic

float easeInElastic(float t, float amplitude = 1.0f, float period = 0.3f);

easeOutElastic

float easeOutElastic(float t, float amplitude = 1.0f, float period = 0.3f);

easeInOutElastic

float easeInOutElastic(float t, float amplitude = 1.0f, float period = 0.45f);

参数

参数 类型 说明 默认
t float 归一化时间 [0, 1]，通常来自 easevalue::frame / totalframe —
amplitude float 弹性振幅，值越大振荡幅度越强。
推荐范围：0.1f ~ 2.0f。 		1.0f
period float 振荡周期，值越小振荡频率越高。
典型值：0.3f（柔和）、0.1f（急促）。 		0.3f
easeInElastic — 弹性蓄力
像拉弓蓄力后释放，有振荡。
easeOutElastic — 弹性过冲
到达终点后像弹簧一样来回振荡衰减。
easeInOutElastic — 双向弹性
两端都有弹簧振荡效果，最夸张。
