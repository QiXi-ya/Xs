xs::XText 类

命名空间：xs | 所属类：XText

概述

xs::XText 提供文字绘制、字体管理与文本测量功能。所有方法均为静态。

FontAdjustType 枚举

定义文本对齐方式。

值说明
ADJUST_LEFT左对齐
ADJUST_RIGHT右对齐
ADJUST_CENTER中心（居中）对齐
ADJUST_TOP上对齐
ADJUST_BOTTOM下对齐

参数

参数类型说明

yfloat坐标 y。

SetFontAdjust

设置文本对齐方式。

void SetFontAdjust(FontAdjustType horizontal, FontAdjustType vertical);

参数

参数类型说明
horizontalFontAdjustType水平对齐：ADJUST_LEFT 左对齐 / ADJUST_RIGHT 右对齐 / ADJUST_CENTER 中心对齐。
verticalFontAdjustType垂直对齐：ADJUST_TOP 上对齐 / ADJUST_BOTTOM 下对齐 / ADJUST_CENTER 中心对齐。
