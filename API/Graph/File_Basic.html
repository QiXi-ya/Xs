命名空间：xs | 所属类：XFile

存在判断

Exists

 bool Exists(const Path& path);

参数

参数类型说明
pathconst Path&要判断的文件或文件夹路径。

返回值

路径存在返回 true，否则返回 false。

IsFile

 bool IsFile(const Path& path);

参数

参数类型说明
pathconst Path&要判断的路径。

返回值

路径指向一个文件返回 true，否则返回 false。

IsDirectory

 bool IsDirectory(const Path& path);

参数

参数类型说明
pathconst Path&要判断的路径。

返回值

路径指向一个文件夹返回 true，否则返回 false。

创建目录

CreateDirectory

 bool CreateDirectory(const Path& path);

参数

参数类型说明
pathconst Path&要创建的目录路径（最子级目录）。

返回值

创建成功返回 true，失败（权限不足、路径非法等）返回 false。

会自动递归创建所有不存在的父目录。

删除

Remove

 bool Remove(const Path& path);

参数

参数类型说明
pathconst Path&要删除的文件或文件夹路径。

返回值

删除成功返回 true，失败返回 false。

删除文件夹时不会弹出确认，请谨慎调用。

重命名 / 移动

Rename

 bool Rename(const Path& src, const Path& dst);

参数

参数类型说明
srcconst Path&源文件路径。
dstconst Path&新文件路径（可跨目录，实现移动效果）。

返回值

重命名成功返回 true，失败返回 false。

复制

Copy

 bool Copy(const Path& src, const Path& dst, bool overwrite = true);

参数

参数类型说明
srcconst Path&源文件路径。
dstconst Path&目标文件路径。
overwritebool是否覆盖已存在的目标文件，默认 true。

返回值

复制成功返回 true，失败返回 false。

遍历

ListFiles

 std::vector<Path> ListFiles(const Path& dir);

参数

参数类型说明
dirconst Path&要遍历的文件夹路径。

返回值

返回该文件夹下所有文件的路径数组（不含子文件夹）。

ListDirectories

 std::vector<Path> ListDirectories(const Path& dir);

参数

参数类型说明
dirconst Path&要遍历的文件夹路径。

返回值

返回该文件夹下所有子文件夹的路径数组（不含文件）。

ListAll

 std::vector<Path> ListAll(const Path& dir);

参数

参数类型说明
dirconst Path&要遍历的文件夹路径。

返回值

返回该文件夹下所有文件和子文件夹的路径数组。

文件大小

Size

 uint64_t Size(const Path& path);

参数

参数类型说明
pathconst Path&要获取大小的文件路径。

返回值

返回文件大小（字节）；路径无效时返回 0。
