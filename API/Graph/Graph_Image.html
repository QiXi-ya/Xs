xs::XImage 类

命名空间：xs | 所属类：XImage

概述

xs::XImage 提供图片对象的创建、属性控制与绘制功能。所有成员均为静态。

NewImage（文件·窄字符）

从文件创建图像（窄字符路径）。

bool NewImage(IMAGE& img, const std::string& filename, int x = 0, int y = 0, int w = 0, int h = 0);

参数

参数类型说明
imgIMAGE&输出图像对象。
filenameconst std::string&文件路径。
xint索取图像的 x 坐标，默认 0。
yint索取图像的 y 坐标，默认 0。
wint索取图像的宽，默认 0（取全部）。
hint索取图像的高，默认 0（取全部）。

返回值

成功返回 true，失败返回 false。

NewImage（文件·宽字符）

从文件创建图像（宽字符路径）。

bool NewImage(IMAGE& img, const std::wstring& filename, int x = 0, int y = 0, int w = 0, int h = 0);

参数

参数类型说明
imgIMAGE&输出图像对象。
filenameconst std::wstring&文件路径（宽字符）。
x, yint索取图像的起始坐标，默认 0。
w, hint索取图像的宽高，默认 0（取全部）。

返回值

成功返回 true，失败返回 false。

NewImage（窗口）

从窗口上获取图像（截图）。

bool NewImage(RenWin& window, IMAGE& img, int x = 0, int y = 0, int w = 0, int h = 0);

参数

参数类型说明
windowRenWin&源窗口。
imgIMAGE&输出图像对象。
xintx 坐标，默认 0。
yinty 坐标，默认 0。
wint宽，默认 0。
hint高，默认 0。

返回值

成功返回 true，失败返回 false。

NewImage（图片）

从另一图像上获取图像。目标图像不保留原有的颜色滤镜，但 src 会以颜色滤镜的形式覆盖 dest。

bool NewImage(IMAGE& dest, IMAGE& src, int x = -1, int y = -1, int w = -1, int h = -1);

参数

参数类型说明
destIMAGE&目标图像。
srcIMAGE&原图像。
xint获取的 x 坐标，默认 -1（自动）。
yint获取的 y 坐标，默认 -1（自动）。
wint获取的宽，默认 -1（自动）。
hint获取的高，默认 -1（自动）。

返回值

成功返回 true，失败返回 false。
