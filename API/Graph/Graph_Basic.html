xs::XGraph 类

命名空间：xs | 所属类：XGraph

概述

xs::XGraph 提供基础几何图形绘制能力与全局绘图状态管理。所有成员均为静态，无需实例化即可调用。

全局绘图状态（颜色、线宽、线型等）在所有子类中共享，会持续影响后续绘制操作，直到再次修改。

LineType 枚举

定义线条的绘制样式。

值说明
LINE_SOLID实线
LINE_CENTER虚线
LINE_DOTTED点线

LineCapType 枚举

定义线条端点的样式。

值说明
LINECAP_FLAT平头（无延伸）
LINECAP_ROUND圆头（默认）
LINECAP_SQUART方头

备注

  • 所有绘制方法立即生效，不自动刷新窗口，需配合窗口的显示逻辑使用。
  • 全局状态（颜色、线宽等）是跨子类共享的，例如 SetLineWidth 会影响 Rect、Circle 等所有描边操作。
  • 角度参数统一使用度（°），顺时针为正方向。
