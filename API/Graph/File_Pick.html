File_Pick

命名空间：xs | 所属类：XFile::Pick

文件过滤器

用于限制对话框中可显示的文件类型，由描述与扩展名组成。

类型定义

using FileFilter  = std::pair<std::wstring, std::wstring>;
using FileFilters = std::vector<FileFilter>;

过滤器示例

// 描述 + 扩展名（分号分隔多个）
{ L"图片文件", L"*.png;*.jpg;*.bmp" }
{ L"文本文件", L"*.txt" }
{ L"所有文件", L"*.*" }

PickFiles（宽字符）

PickFiles

 std::vector<Path>
PickFiles(
    const std::wstring& title = L"选择文件",
    const FileFilters& filters = {},
    const std::wstring& initialDir = {},
    bool multiSelect = true
);

参数

参数类型说明
titleconst std::wstring&对话框标题，默认 L"选择文件"。
filtersconst FileFilters&文件过滤器列表，为空则显示所有文件。
initialDirconst std::wstring&初始打开的文件夹路径，为空则使用上次位置。
multiSelectbool是否允许多选，默认 true。

返回值

返回用户选择的文件路径数组；用户取消时返回空数组。

示例

// 选择多个图片
FileFilters filters = {
    { L"图片", L"*.png;*.jpg;*.bmp" }
};
auto files = XFile::Pick::PickFiles(L"请选择图片", filters, L"", true);
