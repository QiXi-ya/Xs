xs::XImageEx 类

命名空间：xs | 所属类：XImageEx

概述

xs::XImageEx 提供高级图像处理能力，包含模糊、扭曲、羽化、特效、颜色变换、颜色替换与缩放七大类。

所有方法均直接修改传入的 IMAGE 对象，操作不可逆，建议先备份原图。

ImageBlur::Gaussian

高斯模糊。

void Gaussian(IMAGE& img, double sigma);

参数

参数类型说明
imgIMAGE&目标图像。
sigmadouble模糊强度，推荐 2.0~4.0。
