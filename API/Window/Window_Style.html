Window_Style

命名空间：xs | 所属类：XWindow

添加样式

AddWindowStyle

bool AddWindowStyle(HWND hwnd, LONG style);
bool AddWindowStyle(RenWin& window, LONG style);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
styleLONG要添加的 Win32 窗口样式（见下方样式参考）。

返回值

成功返回 true，失败返回 false。

常用值：WS_POPUP、WS_BORDER、WS_THICKFRAME。 完整列表见下方 Win32 窗口样式参考。

Win32 窗口样式参考（WS_*）

以下为可直接传给 AddWindowStyle / RemoveWindowStyle 的 style 参数值。

基础样式

常量值说明
WS_POPUP0x80000000弹出式窗口（无边框、无标题栏）
WS_CHILD0x40000000子窗口
WS_MINIMIZE0x20000000窗口初始为最小化
WS_VISIBLE0x10000000窗口初始可见
WS_DISABLED0x08000000窗口不可交互
WS_CLIPSIBLINGS0x04000000裁剪兄弟窗口重叠区域
WS_CLIPCHILDREN0x02000000绘制时不绘制子窗口区域
WS_MAXIMIZE0x01000000窗口初始为最大化

边框与标题栏

常量值说明
WS_BORDER0x00800000细边框
WS_DLGFRAME0x00400000对话框风格边框（无标题栏）
WS_VSCROLL0x00200000垂直滚动条
WS_HSCROLL0x00100000水平滚动条
WS_SYSMENU0x00080000标题栏带系统菜单
WS_THICKFRAME0x00040000可调整大小的边框
WS_CAPTION0x00C00000标题栏（= WS_BORDER | WS_DLGFRAME）
WS_OVERLAPPED0x00000000重叠窗口（默认）
WS_OVERLAPPEDWINDOW0x00CF0000标准主窗口（标题栏 + 边框 + 系统菜单 + 最大/最小化）
WS_POPUPWINDOW0x80880000弹出窗口（WS_POPUP + WS_BORDER + WS_SYSMENU）

常用组合（推荐）

场景推荐样式组合
无边框窗口WS_POPUP | WS_VISIBLE
标准窗口（默认）WS_OVERLAPPEDWINDOW | WS_VISIBLE
不可调整大小WS_OVERLAPPED | WS_CAPTION | WS_SYSMENU | WS_VISIBLE
全屏无边框WS_POPUP | WS_VISIBLE | WS_CLIPCHILDREN

Win32 扩展样式参考（WS_EX_*）

以下为可直接传给 AddWindowExStyle / RemoveWindowExStyle 的 style 参数值。

外观与层级

常量值说明
WS_EX_DLGMODALFRAME0x00000001对话框模态边框
WS_EX_NOPARENTNOTIFY0x00000004子窗口不通知父窗口
WS_EX_TOPMOST0x00000008窗口置顶
WS_EX_ACCEPTFILES0x00000010接受拖放文件
WS_EX_TRANSPARENT0x00000020点击穿透（不接收鼠标消息）
WS_EX_MDICHILD0x00000040MDI 子窗口
WS_EX_TOOLWINDOW0x00000080工具窗口（不在 Alt+Tab 中显示）
WS_EX_WINDOWEDGE0x00000100窗口带凸起边框
WS_EX_CLIENTEDGE0x00000200窗口内凹边框
WS_EX_CONTEXTHELP0x00000400标题栏带问号按钮

分层与透明（常用）

常量值说明
WS_EX_LAYERED0x00080000分层窗口，支持透明度和 Alpha 混合（做半透明窗口必备）
WS_EX_NOACTIVATE0x08000000窗口不抢焦点（鼠标穿透 + 不激活）

高 DPI / 深色模式

常量值说明
WS_EX_NOREDIRECTIONBITMAP0x00200000无重定向位图（适用于 DWM 全屏翻转）
WS_EX_COMPOSITED0x02000000使用双缓冲绘制，减少闪烁
场景推荐扩展样式组合 半透明窗口WS_EX_LAYERED | WS_EX_TRANSPARENT 置顶工具窗口WS_EX_TOPMOST | WS_EX_TOOLWINDOW 不抢焦点的覆盖层WS_EX_NOACTIVATE | WS_EX_LAYERED | WS_EX_TRANSPARENT 标准主窗口扩展WS_EX_WINDOWEDGE | WS_EX_ACCEPTFILES
