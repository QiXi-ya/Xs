Window_DWM

命名空间：xs | 所属类：XWindow::DWM

所有函数均提供两种重载：接受 HWND 句柄或 RenWin& 渲染窗口。
只有Windows11+具有DWM特效，Windows10无效果。

圆角

SetWindowRoundCorner

设置窗口的圆角样式。

void SetWindowRoundCorner(HWND hwnd, WindowCorner round);
void SetWindowRoundCorner(RenWin& window, WindowCorner round);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
roundWindowCorner圆角类型：CORNER_ROUND（大圆角）、CORNER_SMALLROUND（小圆角）、CORNER_NOROUND（方角）。

边框颜色

SetWindowBorderColor

设置窗口边框的颜色。

void SetWindowBorderColor(HWND hwnd, Color color);
void SetWindowBorderColor(RenWin& window, Color color);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
colorColor边框颜色（RGBA）。设置为透明色可隐藏边框。

标题栏

SetWindowTitleBarColor

设置窗口标题栏的背景颜色。

void SetWindowTitleBarColor(HWND hwnd, Color color);
void SetWindowTitleBarColor(RenWin& window, Color color);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
colorColor标题栏背景颜色（RGBA）。

SetWindowTitleTextColor

设置窗口标题栏文字的颜色。

void SetWindowTitleTextColor(HWND hwnd, Color color);
void SetWindowTitleTextColor(RenWin& window, Color color);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
colorColor标题栏文字颜色（RGBA）。通常配合深色/浅色模式使用。

背景类型

SetWindowBackType

设置窗口的背景类型（模糊、云母等 Windows 11 特效）。

void SetWindowBackType(HWND hwnd, WindowBackType type);
void SetWindowBackType(RenWin& window, WindowBackType type);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
typeWindowBackType背景类型：BACKTYPE_AUTO（自动）、BACKTYPE_BLUR（模糊）、BACKTYPE_MICA（云母）、BACKTYPE_HEAVYMICA（重度云母）、BACKTYPE_NULL（无背景）。

深色模式

SetWindowDarkMode

设置窗口是否启用深色模式。

void SetWindowDarkMode(HWND hwnd, bool EnableDarkMode);
void SetWindowDarkMode(RenWin& window, bool EnableDarkMode);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
EnableDarkModebooltrue 启用深色模式，false 使用浅色模式。

启用或禁用窗口阴影效果。

void EnableWindowShadow(HWND hwnd, bool enable);
void EnableWindowShadow(RenWin& window, bool enable);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
enablebooltrue 启用窗口阴影，false 禁用。

客户区扩展

ExtendIntoClientArea

将客户区扩展到非客户区（标题栏区域），用于实现自定义标题栏。

void ExtendIntoClientArea(HWND hwnd, int top, int bottom, int left, int right);
void ExtendIntoClientArea(RenWin& window, int top, int bottom, int left, int right);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
topint上边距扩展量（像素），将客户区向上延伸至标题栏。
bottomint下边距扩展量（像素）。
leftint左边距扩展量（像素）。
rightint右边距扩展量（像素）。

动画

禁用窗口的过渡动画效果（如最小化/还原动画）。

void DisableTransitionAnimation(RenWin& window, bool disable);

参数

参数类型说明
hwndHWND目标窗口句柄。
windowRenWin&目标渲染窗口。
disablebooltrue 禁用过渡动画，false 恢复默认动画。
