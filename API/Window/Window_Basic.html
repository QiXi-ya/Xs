Window_Basic

命名空间：xs | 所属类：XWindow

枚举

WindowCorner — 窗口圆角类型

值说明
CORNER_ROUND大圆角
CORNER_SMALLROUND小圆角
CORNER_NOROUND方角（无圆角）

WindowBackType — 窗口背景类型

值说明
BACKTYPE_AUTO自动选择背景类型
BACKTYPE_BLUR模糊背景
BACKTYPE_MICA云母背景（Windows 11）
BACKTYPE_HEAVYMICA重度云母背景（更强效果）
BACKTYPE_NULL无背景

窗口基础

SetDPIAware

启用程序的高 DPI 感知，避免在高分辨率屏幕上界面模糊。

void SetDPIAware();

CreateGraphWindow

创建一个图形渲染窗口。

void CreateGraphWindow(
    RenWin& Dest,
    int x, int y,
    int w, int h,
    std::string title = "window",
    uint32_t style = 7U,
    sf::State state = State::Windowed);

参数

参数类型说明
DestRenWin&目标渲染窗口，函数将在此窗口上创建渲染上下文。
xint窗口 X 坐标；小于 0 时使用系统默认位置。
yint窗口 Y 坐标；小于 0 时使用系统默认位置。
wint窗口宽度；小于 0 时使用系统默认尺寸。
hint窗口高度；小于 0 时使用系统默认尺寸。
titlestd::string窗口标题栏文字，默认为 "window"。
styleuint32_t窗口样式标志位组合，默认值为 7U。
statesf::State窗口初始状态，默认为 State::Windowed（窗口化）。

DelayFps

以指定帧率上限刷新窗口，控制主循环节奏。

void DelayFps(int fps, RenWin& Dest);

参数

参数类型说明
fpsint帧率上限（每秒帧数）。
DestRenWin&目标渲染窗口。

SetBackGroundColor

设置窗口的清除背景颜色。

void SetBackGroundColor(Color color);

参数

参数类型说明
colorColor要设置的背景颜色（RGBA）。

IsFocus

判断指定窗口是否为当前焦点窗口。

bool IsFocus(RenWin& Dest);

参数

参数类型说明
DestRenWin&目标渲染窗口。

返回值

若窗口为当前焦点窗口则返回 true，否则返回 false。

大小与位置

MoveWindow

将窗口移动到指定屏幕坐标。

void MoveWindow(RenWin& Dest, int x, int y);

参数

参数类型说明
DestRenWin&目标渲染窗口。
xint新的 X 坐标（屏幕坐标）。
yint新的 Y 坐标（屏幕坐标）。

SetWindowSize

设置窗口的宽高。

void SetWindowSize(RenWin& Dest, int width, int height);

参数

参数类型说明
DestRenWin&目标渲染窗口。
widthint要设置的窗口宽度（像素）。
heightint要设置的窗口高度（像素）。

GetWindowSize

获取窗口当前的宽高。

Vector2i GetWindowSize(RenWin& Dest);

参数

参数类型说明
DestRenWin&目标渲染窗口。

返回值

返回包含窗口宽高的 Vector2i。

GetWindowPos

获取窗口当前在屏幕上的坐标。

Vector2i GetWindowPos(RenWin& Dest);

参数

参数类型说明
DestRenWin&目标渲染窗口。

返回值

返回包含窗口 X/Y 坐标的 Vector2i。

参数
