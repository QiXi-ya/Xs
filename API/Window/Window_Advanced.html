Window_Advanced

命名空间：xs | 所属类：XWindow::Advanced

本类所有设置必须在 CreateGraphWindow 之前调用，否则不会生效。

抗锯齿

SetWindowAntiAliasingLevel

设置窗口的 OpenGL 多重采样抗锯齿（MSAA）等级。

void SetWindowAntiAliasingLevel(unsigned int level);

参数

参数类型说明
levelunsigned int抗锯齿采样等级。常见值为 0（关闭）、2、4、8（最高质量）。值越高画面越平滑，性能开销越大。
注意：必须在 CreateGraphWindow 之前调用。

深度缓冲

SetDepthBits

设置 OpenGL 深度缓冲的位数。

void SetDepthBits(unsigned int Bits);

参数

参数类型说明
Bitsunsigned int深度缓冲位数。常见值为 16、24（推荐）、32。位数越高深度精度越好，可避免 Z-fighting。
注意：必须在 CreateGraphWindow 之前调用。

模板缓冲

SetStencilBits

设置 OpenGL 模板缓冲的位数。

void SetStencilBits(unsigned int Bits);

参数

参数类型说明
Bitsunsigned int模板缓冲位数。常见值为 0（不使用）、8（推荐）。用于模板测试实现遮罩效果。
注意：必须在 CreateGraphWindow 之前调用。

OpenGL 版本

SetOpenGLVersion

设置窗口要使用的 OpenGL 版本。

void SetOpenGLVersion(unsigned int version);

参数

参数类型说明
versionunsigned intOpenGL 版本号，格式为三位数。例如 330 表示 OpenGL 3.3，410 表示 OpenGL 4.1。
注意：必须在 CreateGraphWindow 之前调用。

上下文属性

SetAttributeFlags

设置 OpenGL 上下文属性标志位。

void SetAttributeFlags(ContextSettings::Attribute flags);

参数

参数类型说明
flagsContextSettings::AttributeOpenGL 上下文属性标志位，用于启用调试上下文、核心配置等高级特性。
注意：必须在 CreateGraphWindow 之前调用。

sRGB

SetSRgbCapable

设置是否启用 sRGB 色彩空间缓冲。

void SetSRgbCapable(bool enable);

参数

参数类型说明
enablebooltrue 启用 sRGB 色彩空间（推荐用于色彩准确的渲染），false 禁用。
注意：必须在 CreateGraphWindow 之前调用。
